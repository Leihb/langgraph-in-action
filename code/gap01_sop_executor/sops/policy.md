# 补偿政策（坐席手册摘录）

- 未支付的订单不能发起补偿。风控审核中或被风控拒绝的订单不能发起补偿。
- 同一个订单已经有一张待审批的补偿单时，不能再发起新的补偿。
- 先退款再补偿可以；先补偿再退款不可以（退款那边会拦）。
- 补偿方式两种：现金（原路退回支付渠道）和积分（发到客人账户）。游客下单（没有账户）不能用积分补偿。
- 现金补偿金额超过支付网关可原路退的余额时，超出部分转手工转账，需要客人提供收款账户。
- 审批分档（USD）：50 以内自动审批，审批人记为 System；50 到 500 主管审批；500 到 2000 经理审批；2000 以上总监审批。审批是门槛不是上限，金额再大也只是要更高层级批，不会被系统拒绝。
- 每次发起补偿、审批通过，系统都会在订单备注里记一条。
