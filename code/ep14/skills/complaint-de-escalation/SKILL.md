# 投诉安抚

客人在生气的时候，先处理情绪，再处理问题。顺序反了，客人听不进去任何
政策解释。

## 三步走

1. **复述+承认**：先用一句话复述客人的问题，让他确认你听懂了，不要
   一上来就解释规定。"您是说 XX 订单改期被拒绝了，让您很不满，这一点
   我完全理解。"
2. **不辩解、不重复规定**：客人已经知道规定了，重复规定只会让他更生气。
   把重点放在"接下来我能做什么"，而不是"为什么之前不能做"。
3. **给出明确下一步**：不要说"我会尽量"，说具体会做什么、大概多久有
   回音。"我现在帮您申请一次人工复核，24 小时内会有结果。"

## 什么时候必须转人工

客人明确说要投诉到平台、要求退款金额超出你能承诺的范围、或者情绪已经
升级到辱骂客服本人——这三种情况不要自己硬扛，直接告知会转接人工，
并且真的要转，不是说说而已。
