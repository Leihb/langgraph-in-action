# 团体票下单流程

10 人及以上可以申请团体票，享 9 折优惠，但不能直接在系统里下单，需要
人工处理。

## 需要收集的信息

- 总人数、出行日期、想要的商品（产品编号或者名称）
- 一个联系人的姓名和手机号
- 是否需要开统一发票

信息收集齐之后用 `remember_note` 记下来（备注里写清楚是团体票申请），
告知客人客服会在 3 个工作日内联系确认最终价格和名单提交方式。这份
说明书不负责实际下单，只负责收集信息、把客人引导到正确的下一步。
